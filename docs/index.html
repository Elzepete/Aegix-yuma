Escudo Yuma · aegix

Intermediario antifraude para Yuma Pay, una billetera ficticia de la hackatón: decide antes de que salga un peso si una operación se aprueba, pide un código, espera a un analista o se rechaza.

  • 81,5 % del fraude detectado (línea base 62,6 %)
  • 17,7 % de falsos positivos (hoy 89 %)
  • 5,3 ms de latencia p99
  • ArquitecturaDónde corre cada pieza, las nueve etapas de aegix, un envío retenido paso a paso, cómo se calcula el puntaje y el ciclo del analista.
  • Presentar el proyectoDiagramas de flujo, qué comando correr según dónde presentes, lista de verificación y qué hacer si algo falla.
  • DesplieguePublicar gratis: GitHub, Vercel, túnel con dirección fija y avisos al celular.
  • Reporte de indicadoresCifras medidas, validación temporal y escenarios de ataque.
  • ExplicabilidadCómo decide aegix, cada señal con su peso, accesibilidad y límites.
  • Guion de demoCinco minutos con tiempos y preguntas probables.
